About this snapshot & how to publish

A faithful starting point

All 54 talents, every rank description, grid position, rank cap, spell cost, and prerequisite are preserved from the Talents Forever mage calculator. Data generated October 4, 2026; retrieved October 5, 2026. Source client: 1.60.1.70170. Beta tuning can change after this snapshot.

Rows require 5 points per tier in earlier rows of the same tree. Arrows require a maxed prerequisite. Level 60 has 51 points. Ability damage and costs reproduce source tooltip values; this is a talent planner, not a damage simulator.

Publish on GitHub Pages

  1. Create a GitHub repository.
  2. Upload the downloaded file as index.html at its root.
  3. Open Settings → Pages, choose Deploy from a branch, then main / (root) and Save.
  4. Use your Pages URL to share builds and proposals.

Everything is inside the HTML, including artwork. No build tools or server required. Edit locally, then download HTML again to publish your proposal as the page's starting state.

Proposal edits are local until you share a link, export, or publish. Drafts stay in this browser. Links include both builds, edits, and design notes. Large proposals are best shared as downloaded HTML.
